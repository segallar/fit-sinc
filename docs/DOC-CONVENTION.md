# Соглашение о документировании GetSync



> **Создано:** 2026-05-26 · **Обновлено:** 2026-05-26 · **Версия:** 0.7.0  
> Этот файл — нормативное соглашение для всей папки `docs/`.  
Единые правила для файлов в `docs/`, корневого `README.md` и `CHANGELOG.md`.

---

## Зачем метаданные

| Поле | Назначение |
| ---- | ---------- |
| **Создано** | Дата появления документа в репозитории (первый коммит файла). **Не менять** при правках. |
| **Обновлено** | Дата последнего **смыслового** изменения (факты, API, UI, команды). |
| **Версия** | Версия **продукта** (`getsync` в `pyproject.toml`), к которой привязано содержание на момент обновления. |

Так видно, устарел ли текст относительно текущего релиза (сейчас см. [`getsync/__init__.py`](../getsync/__init__.py) и [CHANGELOG.md](../CHANGELOG.md)).

---

## Шапка документа (обязательно)

Сразу после заголовка `# …` — блок цитаты. **Первая строка** всегда метаданные:

```markdown
# Название документа

> *(опционально: ID roadmap, ссылки, статус задачи)*

Текст…
```

### Правила

1. Формат даты: **ISO `YYYY-MM-DD`** (без времени).
2. Разделитель полей в первой строке: пробел · **`·`** пробел.
3. **Версия** — три числа SemVer, как в пакете на момент правки.
4. Дополнительный контекст — со **второй** строки блока `>` (ID **2.10**, ссылки на PLAN, «не реализовано», …).
5. После шапки — `---` только если он уже был в документе (не вводить лишние разделители).

### Архив (`docs/archive/`)

Первая строка та же, плюс вторая строка:

```markdown
> **Статус:** архив — не обновлять под новые задачи; актуально [PLAN.md](../PLAN.md).
```

Для замороженного снимка можно указать **Версия:** `0.6.0` (версия на момент архивации), не поднимать до `0.7.0` без явной ревизии.

## Когда обновлять поля

| Действие | Создано | Обновлено | Версия |
| -------- | ------- | --------- | ------ |
| Опечатка, пунктуация | — | по желанию | — |
| Новый факт (URL, env, схема БД) | — | **да** | **да**, если релиз сменился |
| Рефакторинг кода без смены поведения в доке | — | нет | нет |
| Новый релиз, док ещё верен | — | **да** | **да** |
| Документ устарел, только ссылка на PLAN | — | **да** | оставить или пометить архив |

**Создано** менять только если файл переименован/скопирован с сохранением истории — тогда в теле указать «ранее …».

## Именование и размещение

| Тип | Путь | Пример |
| --- | ---- | ------ |
| Индекс | `docs/README.md` | навигация |
| Архитектура / ops | `docs/ARCHITECTURE.md`, `CI-CD.md` | |
| Roadmap-задача | `docs/{id}-{NAME}.md` | `2.1-REGISTER.md`, `3.11-GARMIN-PULL.md` |
| Дизайн | `docs/design/` | wireframes, feedback |
| Архив | `docs/archive/` | закрытые планы |
| Релизы | `CHANGELOG.md` | Keep a Changelog |
| Соглашение | `docs/DOC-CONVENTION.md` | этот файл |

Язык: **русский** для prose; идентификаторы кода, env, URL — как в репозитории.

## Связь с версией продукта

| Источник правды | Назначение |
| --------------- | ---------- |
| `getsync/__init__.py` · `pyproject.toml` | текущая разработка |
| Git-тег `v0.6.0`, … | зафиксированные релизы |
| [CHANGELOG.md](../CHANGELOG.md) | что вошло в релиз |
| [PLAN.md](PLAN.md) | что планируется (v0.7, H1, H3) |

В документе поле **Версия** ≠ «версия документа». Это **версия системы**, под которую написан текст.

## Индекс и проверка

- В [README.md](README.md) в таблице навигации — ссылка на это соглашение.
- При MR с изменением `docs/**` — обновить **Обновлено** и при необходимости **Версия** в затронутых файлах.
- Опционально (локально):

```bash
git log -1 --format='%ad' --date=short -- docs/PLAN.md   # последнее изменение
git log --diff-filter=A --format='%ad' --date=short -1 -- docs/PLAN.md  # создание
python3 scripts/docs_apply_meta.py   # массово проставить/обновить первую строку шапки (см. FILES в скрипте)
```
