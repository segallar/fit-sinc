## Как добавлять замечания

1. **В чат** — списком; ассистент перенесёт сюда с номерами.
2. **Прямо в файл** — копировать шаблон строки ниже.
3. **Один пункт = одно наблюдение** (не смешивать «шрифт + nav + таблица»).

### Шаблон строки

```markdown
| D-??? | P? | экран | тип | Замечание | Предложение (опционально) | статус |
```

| Поле | Значения |
| ---- | -------- |
| **ID** | `D-001`, `D-002`, … |
| **P** | **P0** блокер · **P1** важно · **P2** полировка · **P3** идея |
| **тип** | layout · nav · typography · color · spacing · table · form · calendar · copy · a11y · mobile |
| **статус** | `new` · `accepted` · `wontfix` · `done` |

**Контекст (если важно):** desktop / mobile · prod pills vs ui-preview sidebar · List vs Calendar.
